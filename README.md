# Lokal Music Player

This is a simple music player mobile application built using React Native and Expo.

The application allows users to search for songs using a real API, play music, and control playback through a mini player and a full screen player.

## Features

- Search songs using a real music API (JioSaavn)
- Display song list with album artwork
- Play / Pause music
- Mini player that sticks to the bottom of the screen
- Full screen player with song details
- Progress bar with current time and duration
- Tap on progress bar to seek
- State management using Zustand
- No mock or static data used

## Tech Stack

- React Native
- Expo
- TypeScript
- Zustand (state management)
- Expo AV (audio playback)
